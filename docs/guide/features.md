# 核心特性

## 协议与性能

- 支持 HTTP/HTTPS/HTTP2/HTTP3 多协议接入
- 支持 fasthttp 与 nbio 等高性能路径
- 支持静态资源直通与多种代理模式协同

## 安全与流量治理

- PreAuth 前置认证，支持 OAuth2、Basic、JWT 多模式
- 请求头清洗与域名预检查，降低伪造和绕过风险
- 限流与熔断策略，提升高峰期稳定性
- 防盗链、响应安全头、CORS 等安全增强能力

## 可观测与运维能力

- 按域名统计请求数据，支持地理维度分析
- 健康探针用于存活性与可用性检测
- 延迟服务与时序统计便于性能分析
- 支持 reload 流程，提升配置变更效率

## 扩展生态

- WASM 插件支持请求和响应生命周期钩子
- gRPC 管理面可执行状态查询、配置重载与服务控制
- 实验模块支持 VPN、AnyTLS 与 Trojan 服务接入

## 适用场景

| 场景 | 价值 |
| --- | --- |
| 多域名业务入口统一 | 用单套网关承载多站点路由与转发 |
| 对外 API 安全前置 | 通过预认证和限流提升安全与稳定性 |
| 边缘节点流量治理 | 协议多样化接入并统一策略控制 |
| 平台化二次开发 | 基于 WASM 与 gRPC 扩展自定义能力 |
